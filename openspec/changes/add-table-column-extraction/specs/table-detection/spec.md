## ADDED Requirements

### Requirement: 偵測框線表格的儲存格
系統 SHALL 以 OpenCV 形態學運算從二值影像中找出水平與垂直框線，並回傳每個由框線圍成的儲存格矩形（x、y、寬、高）；表格外的背景區域與寬或高小於 15 像素的區域不得視為儲存格。字元筆畫不得被誤判為框線。

#### Scenario: 2x3 表格
- **WHEN** 影像中有一個 2 列 × 3 欄、框線完整的表格
- **THEN** 系統回傳 6 個儲存格，每個矩形位於對應框線之內

#### Scenario: 無表格頁面
- **WHEN** 影像中只有文字、沒有框線
- **THEN** 系統回傳空清單

#### Scenario: 儲存格內有文字
- **WHEN** 表格儲存格內印有中文字
- **THEN** 儲存格數量不變，文字筆畫不被當成框線

#### Scenario: 大字體的長筆畫
- **WHEN** 頁面上有大字體的 `工`、`口`，其筆畫長度超過框線偵測的結構元素
- **THEN** 這些筆畫不被視為框線，`口` 也不被當成儲存格；只有長度達頁面短邊 1/8 以上（或與其相連）的線段才視為框線
